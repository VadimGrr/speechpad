Проверка вставки

Страница отдаётся агентом с 127.0.0.1, поэтому расширение в неё авторизовано. Щёлкните по нужному полю, продиктуйте фразу и отметьте, что текст появился. Внизу справа — журнал событий вставки.

пункт 28

Обычное текстовое поле

Базовая вставка: курсор должен оказаться в поле.

пункт 28

Многострочное поле

Вставка должна попасть в место курсора, а не в конец.

пункт 28

Редактируемый блок (contenteditable)

Тот же случай для текста без тега input.

пункт 29

Поле пароля

Вставка должна пройти. Chrome не показывает символы — сверяйте длину значения в консоли страницы, а не сам текст.

пункт 30

Поле внутри iframe

Отдельный документ в том же источнике: содержимое вставляется в поле внутри рамки, а не в страницу снаружи.

пункт 31

Страница без полей ввода

Вкладка без полей: Speechpad не должен падать, а показать понятное сообщение. Проверьте вкладку с этой страницей, убрав фокус с полей.

Здесь нет ни одного поля ввода. Кликните по этому месту.
