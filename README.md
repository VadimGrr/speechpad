# Speechpad

Локальный голосовой ввод в любую программу Windows: непрерывное распознавание
речи, два окна (стенограмма + компактное окно поверх других окон), вставка
распознанного текста в сфокусированное поле любого приложения, веб-SDK для
сторонних проектов.

Распознавание выполняется движком Google Web Speech API через Chromium.
Собственных серверов распознавания нет, нужен интернет.

## Требования

- Node.js 20+
- Chrome или Edge (для распознавания)
- .NET SDK 10 (только для нативного агента, фаза P4)

## Быстрый старт ядра

```bash
npm install
npm run typecheck
npm test
npm run build
```

Сборка кладёт в `packages/core/dist`:

- `speechpad.js` — IIFE-бандл с глобальным `Speechpad`, для `<script src>`;
- `speechpad.esm.js` — ESM-версия для сборщиков;
- `index.d.ts` — типы.

## Запуск приложения

```bash
npm run build                                        # собрать веб в apps/web/dist
npm run agent                                        # нативный агент с иконкой в трее
```

Агент поднимает `http://127.0.0.1:8787/`, отдаёт главное окно и вставляет
распознанный текст в активное окно. Только веб, без агента:

```bash
npm run dev                                          # http://127.0.0.1:5173/
```

Ключи агента и протокол: [docs/AGENT.md](docs/AGENT.md).

## Расширение Chrome (по желанию)

```bash
npm run build -w @speechpad/extension
```

`chrome://extensions` → «Режим разработчика» → «Загрузить распакованное
расширение» → папка `apps/extension/dist`. В главном окне появится список
«Куда вставлять»: активное окно Windows (агент) или поле активной вкладки
браузера (расширение — для паролей, iframe и редакторов).

Подробности: [docs/EXTENSION.md](docs/EXTENSION.md).

## Как устроено

```
packages/core    движок и публичный SDK, не зависит от DOM
apps/web         главное и компактное окно
apps/agent       нативный помощник для Windows: вставка текста, хоткеи, трей
apps/extension   расширение Chrome: вставка в поле активной вкладки
docs             план, контракт API, агент, расширение, критерии приёмки
```
