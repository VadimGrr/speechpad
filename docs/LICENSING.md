# Лицензирование

Распознавание идёт в браузере через Web Speech API, проверка лицензии — локально, по подписи. Наш сервер в распознавании не участвует и текст не видит, но сам Web Speech API — облачный сервис: Chrome отправляет аудио в Google, Edge может уводить распознавание на серверы Microsoft. Подробности в разделе «Онлайн-сервисы».

## Как это устроено

1. Лицензия — это JSON-файл `license.json` с двумя полями: `payload` (данные в base64url) и `signature` (подпись ECDSA P-256, SHA-256).
2. Агент хранит только публичный ключ (`apps/agent/Licensing/KeyPair.cs`) и проверяет подпись при каждом чтении файла.
3. Приватный ключ хранится только у вас, в репозитории его нет и не должно быть.
4. Подделать или продлить лицензию на чужом компьютере нельзя: любое изменение `payload` ломает подпись.

## Где лежит файл лицензии

По умолчанию `%APPDATA%\SpeechPad\license.json`. Путь меняется в `settings.json` (`licensePath`) или ключом `--license <путь>`.

## Что проверяется

- версия формата и продукт `speechpad-agent`;
- срок действия (`expires` пустой — бессрочная лицензия);
- привязка к компьютеру (`machine`, если задан);
- наличие нужной возможности: `insert`, `extension`, `topmost`.

Идентификатор компьютера: `sha256("speechpad|<имя компьютера>|<пользователь>|<MachineGuid>")`. Покупатель смотрит его в меню трея: «Идентификатор компьютера». Диагностика из командной строки:

```powershell
speechpad-agent.exe --license-info
```

## Установка лицензии двойным щелчком

Покупателю не нужно ничего знать про папки и командную строку:

1. Портал или инструмент выпускает файл `Speechpad-Фамилия.lic` (обычное содержимое — JSON с подписью).
2. Покупатель запускает `Speechpad.exe` один раз. Агент регистрирует в `HKCU\Software\Classes` связь расширения `.lic` с собой: `"<путь к Speechpad.exe>" --install-license "%1"`.
3. Покупатель открывает `.lic` двойным щелчком. Агент проверяет подпись, показывает окно «Лицензия установлена» и сохраняет файл в `%APPDATA%\SpeechPad\license.json`.
4. Уже запущенный агент подхватывает лицензию при следующем обновлении (клиентский `hello` или пункт меню «Лицензия»).

Если привязки `.lic` ещё нет (например, агент запускали из временной папки), установка доступна из меню трея: «Установить лицензию…».

Из командной строки то же самое:

```powershell
speechpad-agent.exe --install-license D:\Downloads\Speechpad-Иванов.lic
```

Отказ (чужая подпись, другой компьютер, истёкший срок) не трогает уже установленную лицензию и не ломает работу программы.

## Пробный период

Если лицензии нет, агент даёт пробный период (`trialDays` в настройках, по умолчанию 2 дня) и записывает дату первого запуска в `license.json.trial`. Действующая лицензия всегда важнее пробного периода. Чтобы требовать лицензию без пробного периода, поставьте `requireLicense: true`.

## Проверка состояния

```powershell
speechpad-agent.exe --license-info
```

Код возврата `0` — лицензия или пробный период в порядке, `1` — лицензии нет.

Ответ агента `GET /health` содержит `licenseState`, `licenseMessage`, `insertAllowed`, `extensionAllowed`.

## Выпуск лицензии покупателю

Инструмент `tools/speechpad-license` (приватный ключ в него не входит).

```powershell
# выпуск на год для конкретного компьютера
dotnet run --project tools/speechpad-license -- issue C:\secrets\license-private.pem D:\Ivanov.json --licensee "Иван Иванов" --days 365 --machine 441377b2...

# бессрочная лицензия, работает на любом компьютере
dotnet run --project tools/speechpad-license -- issue C:\secrets\license-private.pem D:\Ivanov.json --licensee "Иван Иванов" --all-machines

# только вставка, без расширения и поверх-поверх окон
dotnet run --project tools/speechpad-license -- issue C:\secrets\license-private.pem D:\Ivanov.json --features insert

# посмотреть, что внутри
dotnet run --project tools/speechpad-license -- show D:\Ivanov.json
```

Дальше отправляете покупателю `Ivanov.json`, он кладёт файл в `%APPDATA%\SpeechPad\license.json`.

## Портал выдачи

Для обычной работы портал удобнее командной строки: один вход, форма с получателем, сроком, привязкой и возможностями, история выданных лицензий.

Форма выдаёт файл с расширением `.lic` и именем `Speechpad-Фамилия.lic`. Значение по умолчанию — «любой компьютер»: покупателю не нужно узнавать идентификатор машины. Для строгой привязки выберите «один компьютер» и вставьте идентификатор из меню трея покупателя.

Первый запуск — создать администратора. Пароль вводится один раз, не отображается и не сохраняется открытым текстом:

```powershell
npm run portal:init
```

Запуск портала:

```powershell
npm run portal
```

Откройте `http://127.0.0.1:8790/`. Логин `admin`, пароль — тот, что задали при инициализации.

Портал слушает только `127.0.0.1`, наружу не открывается. Пароль хранится как PBKDF2-HMAC-SHA256 (210 000 итераций, случайная соль) в `portal-admin.json`, сессия — cookie `HttpOnly` + `SameSite=Strict`, изменяющие запросы защищены CSRF-токеном, попытки входа ограничены. Приватный ключ читается только при подписи и в браузер не попадает.

Файлы по умолчанию:

| Что | Путь |
| --- | --- |
| приватный ключ | `C:\Users\vadim\Documents\speechpad-secrets\license-private.pem` |
| администратор | `C:\Users\vadim\Documents\speechpad-secrets\portal-admin.json` |
| история | `C:\Users\vadim\Documents\speechpad-secrets\issued-licenses.json` |

Пути меняются ключами `--private-key`, `--credentials`, `--history`, порт — `--port`.

### Где срок и что в нём

Срок по календарной дате считается до 23:59:59 UTC, поэтому не зависит от часового пояса машины, на которой выдана лицензия.

### Про отзыв

Кнопка «отозвать» в истории помечает запись и не позволяет выдать новую лицензию с тем же ID. Технически подписанный файл у покупателя при этом остаётся рабочим: агент проверяет подпись локально и не обращается к порталу. Настоящий отзыв возможен только с серверной проверкой или с обнулением приватного ключа, что ломает все остальные лицензии.

## Готовый релиз для покупателя

```powershell
npm run release
```

Скрипт `scripts/release.ps1` прогоняет тесты (если не задан `-SkipTests`), собирает веб и расширение, публикует самодостаточный `Speechpad.exe` (`win-x64`, single file, .NET 10) и складывает в `release\Speechpad-<версия>-win-x64.zip`:

```
Speechpad.exe          самодостаточная программа (~60 МБ), .NET не нужен
web/                   окно Speechpad и компактное окно
extension/             Chrome MV3, ставится вручную через chrome://extensions
КАК-УСТАНОВИТЬ.txt     инструкция для покупателя
```

Программа ищет `web/` рядом с собой, поэтому папку из архива нельзя разбрасывать по диску. Инструкция для покупателя: `docs/BUYER-START.md`.

## Смена ключей

```powershell
dotnet run --project tools/speechpad-license -- keygen C:\secrets\license-private.pem C:\secrets\license-public.pem
```

Публичный ключ из `license-public.pem` вставьте в `apps/agent/Licensing/KeyPair.cs` и пересоберите агента. Старые лицензии после смены ключа перестают работать.

## Приватный ключ

Приватный ключ — единственный секрет продукта. Требования:

- не коммитить, не класть в архивы релиза и не отправлять покупателям;
- хранить вне репозитория (текущая копия: `C:\Users\vadim\Documents\speechpad-secrets\license-private.pem`);
- сделать резервную копию в другом месте: потеря ключа означает невозможность выпускать новые лицензии;
- при подозрении на утечку — сгенерировать новый ключ по инструкции выше.
