# План реализации: локальный аналог Speechpad

Источник требований: `SPEECHPAD-REWRITE-PLAN.txt`.
Статус: P0–P5 готовы, P6 (SDK-полировка) — следующий. Обновлять статус в конце каждой фазы.

## 0. Что строим (скоуп)

MVP:
- непрерывный голосовой ввод ru-RU/en через Chromium (Web Speech API);
- два окна: главное (стенограмма + статус) и компактное (поверх других окон, реалтайм);
- режим «ввод в другое приложение Windows»: финальный текст уходит в сфокусированное поле;
- веб-SDK (`speechpad.js`) для встраивания в сторонние проекты;
- настройки: язык, тёмная тема, горячие клавиши, пауза.

Вне MVP: LLM-конспекты/Q&A, диаризация, аккаунты/облако. Движок распознавания —
**только Google Web Speech API**, локальный Whisper не используется.

## 1. Структура репозитория

```
speechpad/
  packages/core/     ядро: engine.ts, webSpeech.ts, dedupe.ts, planner.ts, bus.ts, clock.ts, sdk.ts
                     тесты vitest → build dist/speechpad.js (IIFE, global Speechpad)
  apps/web/          главное окно (index.html) + компактное (float.html), BroadcastChannel 'speechpad'
  apps/agent/        C# .NET 10: WS+HTTP на 127.0.0.1, статика, Injector, Hotkeys, TopMost, Tray, Autostart
  apps/extension/    Chrome MV3: вставка в поля активной вкладки (bridge + background + inserter)
  docs/              PLAN.md API.md AGENT.md EXTENSION.md ACCEPTANCE.md
```

## 2. Принятые решения (отличия от исходного документа)

| Вопрос | Решение | Причина |
| --- | --- | --- |
| Расположение | отдельный репозиторий `Documents\speechpad` | текущий репозиторий смешанный, продукт не должен попасть в него |
| Вставка текста в чужую программу | clipboard + Ctrl+V (SendInput — сменяемый `ITextInjector`) | так же работает «Вывод в буфер обмена» у speechpad.ru; не требует сборки SendInput в MVP |
| Транспорт | один WebSocket агента в обе стороны + `/v1/health` | web→agent: финалы; agent→web: команды хоткеев |
| Хостинг UI | агент сам отдаёт `apps/web/dist` | один origin, токен не утекает левой вкладке, один процесс владеет всем |
| Расширение Chrome | мост `window.postMessage` на loopback-странице, WebSocket агента не используется | расширению не нужен токен агента и WS: вставка идёт напрямую в DOM, авторизация — факт загрузки `bridge.js` только на 127.0.0.1 |
| Абстракция движка | `RecognitionFactory` как шов для тестов | фейковый распознаватель в юнит-тестах, вторые движки не планируются |
| Мониторинг фоновой вкладки | окно с распознаванием держим активным | фоновая вкладка Chrome приглушает Web Speech |

## 3. Защиты непрерывности (ядро, раздел 2 исходного плана)

- `wantRecord` — намерение пользователя; `onend` при `wantRecord === false` не перезапускает.
- Один экземпляр распознавателя; `sessionId` отсекает события предыдущего инстанса.
- Автоперезапуск: базовая задержка 400 мс, экспоненциальный backoff до 3 с.
- `silentEnds`: 3 тихих `onend` подряд → пауза 1.5 с, чтобы не поймать tight loop.
- Watchdog: тишина > 12 с → принудительный рестарт, cooldown 5 с, порог растёт
  экспоненциально (до 60 с), пока результаты не появятся.
- Мягкий рецикл инстанса раз в 25 мин в паузе речи.
- Дедупликация: нормализация (регистр, `ё`→`е`, пунктуация), окно хвоста 200 символов.
- Ошибки: `not-allowed`, `service-not-allowed`, `audio-capture`, `language-not-supported` —
  фатальные; `network`, `no-speech`, `aborted` — ретрай.
- Рендеринг: interim через `partial`, тяжёлое — только на `final`.

## 4. Фазы и критерии выхода

| Фаза | Содержание | Выход |
| --- | --- | --- |
| P0 | монорепо, ts, vitest, git | `npm run typecheck` и `npm test` зелёные |
| P1 | ядро + юнит-тесты всех защит | тесты зелёные без браузера |
| P2 | главное окно: стенограмма, инлайн-интерм, метрики | 5 мин диктовки без дублей, латентность 1–2 с |
| P3 | компактное окно (BroadcastChannel) | та же речь с тем же лагом |
| P4 | агент C#: сервер, WS, инжектор, хоткеи, трей, topmost, автозапуск | текст в Word/браузере, хоткей при чужом фокусе |
| P5 | расширение MV3 | вставка в поля других вкладок |
| P6 | SDK `speechpad.js` + `docs/API.md` | работает в чужом HTML |
| P7 | приёмка по критериям §9, соак 30+ мин, отчёт | заполненный ACCEPTANCE.md |

Фаза P4 закрыта: 81 тест агента (включая живые HTTP и WebSocket проверки) и 91
тест веба зелёные. Протокол, ключи командной строки и настройки агента —
[docs/AGENT.md](AGENT.md). Ручная часть приёмки P4 (текст в Word, хоткей при
чужом фокусе) пройдена 2026-09-29, отчёт в [docs/ACCEPTANCE.md](ACCEPTANCE.md).

Фаза P5 закрыта: 43 теста расширения и 91 тест веба зелёные, сборка
`npm run build -w @speechpad/extension` даёт загружаемую папку `dist`.
Устройство, протокол и ограничения — [docs/EXTENSION.md](EXTENSION.md).

Фаза P6 закрыта по коду: `packages/core/dist/speechpad.js` собирается, таблица
опций сверена с `DEFAULT_OPTIONS`, добавлен посторонний пример
`examples/embed` с командой `npm run example:embed` (страница отдаётся с
`http://127.0.0.1:5174/`, агент и главное окно не нужны). Ручная проверка приёма
микрофона в примере — пункт 7 в [docs/ACCEPTANCE.md](ACCEPTANCE.md).

## 5. Риски

| Риск | Митигация |
| --- | --- |
| Повтор фраз при автоперезапуске | дедупликация + юнит-тесты |
| Фоновая вкладка глушит Web Speech | окно с распознаванием держим активным, компактное окно открывается поверх |
| Порт занят | 17321 → 17331, фактический порт пишется в `%APPDATA%\SpeechPad\agent.json` |
| Агент упал | веб продолжает работать сам, статус «агент недоступен» |
| Защищённые поля (банки, пароли) | SendInput-инжектор как альтернатива Ctrl+V |
| Деградация долгой сессии | рецикл инстанса раз в 25 мин |
| Edge уводит на серверы Microsoft | предупреждение в UI, рекомендация Chrome |
