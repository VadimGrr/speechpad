# Приёмка

Чек-лист из раздела 9 исходного плана плюс проверки фаз P2–P4. Заполняется по
результатам живого прогона, не по тестам.

Как запустить:

```bash
npm run build          # собрать веб в apps/web/dist
npm run agent          # агент с иконкой в трее
```

Главное окно: <http://127.0.0.1:8787/>. Компактное окно открывается кнопкой
«Компактное окно» в главном (или отдельно `/float.html`, но тогда канал
`BroadcastChannel` не сработает — окна должны быть одного origin).

Перед прогоном: Chrome (не Edge), разрешение на микрофон для `127.0.0.1`,
в главном окне включена кнопка «Автовставка» (иначе финалы останутся только в
стенограмме), язык `ru-RU`.

## Обязательные критерии (раздел 9)

| # | Критерий | Как проверять | ✔ |
| --- | --- | --- | --- |
| 1 | Непрерывная диктовка 30+ минут без ручной паузы и без дублей фраз | Говорить 30+ мин, метрики в панели «Метрики»: `restarts`, `duplicatesBlocked`, `silentEnds` | ☑ |
| 2 | Интерм на экране через 1–2 с после начала фразы, финал — сразу по окончании | Смотреть на главное окно и на компактное одновременно | ☑ |
| 3 | После автоперезапуска первый интерм в пределах ~2 с | Замереть вручную по метрике `firstInterimAfterRestartMs` | ☑ |
| 4 | Пауза в речи 30 с+ не рвёт сессию | Молчать 30–60 с, затем говорить без нажатий | ☑ |
| 5 | Переключение «в своё окно» ↔ «в приложение» работает хоткеем | `Ctrl+Alt+Space` при фокусе на чужом окне | ☑ |
| 6 | Компактное окно показывает ту же речь с минимальной задержкой | Говорить, глядя только на компактное окно | ☑ |
| 7 | `<script src="speechpad.js">` работает в чужом HTML | Пример из `docs/API.md` в отдельном файле вне репозитория | ☐ |
| 8 | Все кнопки отражают фактическое состояние движка, «мёртвых» нет | Прогнать все кнопки в обоих окнах | ☐ |

## Известные ограничения (раздел 10 исходного плана)

- Интерм для русского приходит кусками — это поведение серверов Google.
- Нужен интернет и Chrome/Edge; Edge может уводить распознавание к серверам Microsoft.
- `Ctrl+V` не работает в защищённых полях (пароли, банки) — для них `--scheme unicode`.
- Без ручной паузы сессия может «протухать» на длинных диктовках; ядро перезапускает
  распознаватель сам, проверяется метрикой `restarts`.
