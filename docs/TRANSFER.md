# Перенос проекта на другой компьютер

Всё нужное лежит в папке `speechpad` рядом с этим файлом. Это полная копия репозитория
с историей git, без скомпилированного мусора: 3 МБ вместо 400 МБ.

Там же лежит копия на GitHub: https://github.com/VadimGrr/speechpad

## Что понадобится на новом ПК

| Что | Версия |
| --- | --- |
| .NET SDK | 10.0.x — https://dotnet.microsoft.com/download |
| Node.js | 20 или новее — https://nodejs.org |
| Браузер | Chrome или Edge 111+ |

Интернет нужен для установки зависимостей и для распознавания речи.

## Развертывание

```powershell
cd speechpad
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\setup-new-pc.ps1
```

Скрипт проверит версии, выполнит `npm install`, прогонит сборку и все тесты. Если
всё зелёное — окружение готово. Тесты занимают пару минут, это нормально.

## Запуск

```powershell
npm run agent      # агент, потом открыть http://127.0.0.1:8787/
npm run portal:init   # первый раз: создать администратора портала
npm run portal      # портал выдачи на http://127.0.0.1:8790/
npm run release     # собрать ZIP для покупателя
```

## Приватный ключ — перенесите отдельно

Ключа, которым подписываются лицензии, в проекте **нет**, и в истории git его тоже
нет. Он лежал на старом компьютере здесь:

```
C:\Users\vadim\Documents\speechpad-secrets\license-private.pem
```

Если на новом ПК нужно выпускать лицензии, скопируйте эту папку отдельно (не в
репозиторий, не на флешку с исходниками — лучше в другое место) и укажите путь:

```powershell
npm run portal -- --private-key D:\secrets\license-private.pem
```

Потеря ключа означает, что выпустить новые лицензии не получится. Смена ключа
ломает все ранее выданные лицензии.

## Если что-то пошло не так

- `npm install` ругается — удалите `node_modules` и запустите снова.
- Тесты падают на лицензировании — скорее всего, не установлен .NET 10 SDK.
- Агент не запускается — проверьте, свободен ли порт 8787:
  `Get-NetTCPConnection -LocalPort 8787 -State Listen`
- Проблемы с распознаванием — нужен Chrome/Edge и интернет.
- Всё сломалось — проект есть на GitHub, можно клонировать заново:
  `git clone https://github.com/VadimGrr/speechpad.git`

Другие агенты: прочитайте `AGENTS.md` в корне проекта до правок.
