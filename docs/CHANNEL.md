# Протокол синхронизации окон

Компактное окно (`apps/web/float.html`) не запускает движок. Оно получает текст и
состояние из главного окна через `BroadcastChannel('speechpad')` — единственный
канал между окнами. Канал работает только в одном origin, поэтому оба окна
должны быть открыты с одного адреса (`http://127.0.0.1:5173` или собранный статик).

## Сообщения

Все сообщения — один объект с полем `kind`. Неизвестные `kind` и `command`
отбрасываются на приёме (`isSyncMessage` в `apps/web/src/channel.ts`).

| Сообщение | Отправитель | Значение |
| --- | --- | --- |
| `hello` | компактное | «жив?» — ответом будет `snapshot` |
| `snapshot` | главное | полный текст + состояние; ответ на `hello` и синхронизация после ручной правки |
| `state` | главное | состояние движка, `supported`, `hasText`, `theme` |
| `interim` | главное | черновик текущей фразы, рисуется призраком |
| `final` | главное | новая финальная фраза целиком, дописывается в хвост |
| `reset` | главное | стенограмма очищена |
| `command` | компактное | `toggle`, `clear`, `copy`, `focus-main` |
| `bye` | любое | окно закрывается, сбрасывает ссылку на попап |

Поля `snapshot` и `state`: `state` (`idle | listening | paused | error`),
`supported` (есть ли Web Speech API), `hasText`, `theme`, у `snapshot` ещё `text`.

## Правила

- Отправитель не получает собственные сообщения.
- Главное окно — единственный источник истины: движок, стенограмма и localStorage
  живут только там.
- Компактное окно шлёт `hello` раз в 4 с и считает связь потерянной через 10 с
  молчания. При потере связи все кнопки, кроме «Главное» и «✕», блокируются, а в
 низу появляется плашка «Нет связи с главным окном».
- Компактное окно показывает хвост стенограммы (700 символов) и умеет скроллить
  к последней строке; текст в нём только для чтения, правки идут в главном окне.
- Полный `snapshot` вместо `state` приходит и после ручной правки в главном
  окне (с задержкой 400 мс), поэтому компактное окно не показывает устаревший текст.

## Что дальше

`always on top` и глобальные горячие клавиши появляются в `apps/agent`
(раздел 11 плана, шаг 4): нативный хелпер поднимает окно браузера через
`SetWindowPos(HWND_TOPMOST)`. В вебе это сделать нельзя, поэтому кнопки,
которые веб не умеет, в компактное окно не выведены.
