# Speechpad — как установить и начать

1. Распакуйте скачанный ZIP в любую папку (например, `C:\Speechpad`).
2. Запустите `Speechpad.exe`. Появится окно Speechpad, программа останется в трее.
3. Откройте присланный вам файл `Speechpad-Фамилия.lic` **двойным щелчком**.
4. Появится окно «Лицензия установлена». Всё, можно пользоваться.

## Если не сработало двойной щелчок

Откройте меню программы в трее (иконка рядом с часами) и выберите
**«Установить лицензию…»**, затем укажите ваш файл `.lic`.

Идентификатор компьютера, если понадобится привязка к одному ПК, там же:
**«Идентификатор компьютера»**.

## Расширение для браузера (необязательно)

1. Откройте в Chrome страницу `chrome://extensions`.
2. Включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение» и выберите папку `extension`
   из распакованного архива.

## Условия

- Лицензия проверяется на вашем компьютере, интернет не нужен.
- Срок «бессрочно» — ограничений нет. Ограниченный срок действует до даты
  окончания включительно.
- Лицензия хранится в `%APPDATA%\SpeechPad\license.json`.
- Перенос на другой компьютер: просто установите лицензию там заново,
  если она выдана на «любой компьютер».
