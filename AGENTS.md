# Speechpad — заметки для другого агента

Читай перед правками. Здесь то, что не видно из кода и о чём легко сломать продукт.

## Что это

Локальный диктовщик для Windows: голос → текст → вставка в любое активное окно.
Продаётся как подписанная лицензия, выдаётся локальным порталом.

## Железо и версии

| Что | Версия |
| --- | --- |
| .NET SDK | 10.0.x (проверено 10.0.401) |
| Node.js | 20.x или новее (проверено 20.20.2) |
| Браузер | Chrome/Edge 111+ |

Агент — `net10.0-windows`, WinForms + встроенный Kestrel. Расширение — Chrome MV3
с `minimum_chrome_version: 111`.

## Структура

```
apps/agent/            агент: HTTP-сервер, вставка, трей, лицензия (C#, WinForms)
apps/web/              окно Speechpad и компактное окно (Vite + TypeScript)
apps/extension/        Chrome MV3: вставка в поля чужих сайтов
packages/core/         общий код протокола и логики диктовки
tools/speechpad-license/        CLI выпуска лицензий
tools/speechpad-license-portal/ локальный портал выдачи (только 127.0.0.1:8790)
scripts/release.ps1    сборка релиза для покупателя
```

## Команды

Перенос на другой компьютер: `docs/TRANSFER.md`, развёртывание одной командой
`npm run setup`.

```powershell
npm install                # один раз, ставит все workspaces
npm run setup              # проверить .NET/Node, поставить зависимости, прогнать тесты
npm run build              # собрать все JS/TS части
npm run typecheck          # tsc --noEmit по всем workspace
npm run test               # тесты web и расширения (vitest)
npm run test:agent         # тесты агента (xunit)
npm run portal:test        # тесты портала
npm run agent              # запуск агента из исходников
npm run portal             # запуск портала
npm run release            # ZIP для покупателя (53 МБ, self-contained win-x64)
```

Перед сдачей работы прогоняй и `npm run typecheck`, и `npm run test`, и
`npm run test:agent`, и `npm run portal:test`. Сейчас всё зелёное: web 119,
агент 162, портал 42.

## Секреты — не в репозитории

Приватный ключ, от которого подписываются лицензии, лежит **вне** проекта:

```
C:\Users\vadim\Documents\speechpad-secrets\license-private.pem
C:\Users\vadim\Documents\speechpad-secrets\portal-admin.json
C:\Users\vadim\Documents\speechpad-secrets\issued-licenses.json
```

Правила:

- никогда не коммитить `.pem`, `.lic`, `portal-admin.json`, `license.json`;
- не выводить ключ в браузер, лог или архив релиза;
- `.gitignore` уже прикрывает `*.pem`, `*.lic`, `license.json`, `release/`;
- перед коммитом проверяй `git status` — в индексе не должно быть ничего похожего на секрет;
- публичный ключ лежит в коде: `apps/agent/Licensing/KeyPair.cs`. Смена ключа ломает
  все ранее выданные лицензии.

## Лицензирование коротко

1. Лицензия — JSON `{payload, signature}`, подпись ECDSA P-256, SHA-256.
2. Агент проверяет подпись **офлайн**, каждый раз при чтении файла. Портал и интернет
   в проверке не участвуют.
3. Файл по умолчанию: `%APPDATA%\SpeechPad\license.json`.
4. Покупатель ставит лицензию двойным щелчком по `.lic`: агент при первом запуске
   регистрирует расширение в `HKCU\Software\Classes`. Запасной путь — пункт меню трея
   «Установить лицензию…».
5. Отзыв в истории портала **не отключает** уже выданный файл. Настоящий отзыв требует
   серверной проверки или смены ключа. Не обещай покупателям обратного — это враньё.

Подробности: `docs/LICENSING.md`.

## Как распознаётся речь

Через Web Speech API в браузере. **Аудио уходит в Google**, Edge может уводить в Microsoft.
Наш сервер речь не обрабатывает и текста не видит, но облачность распознавания — это
факт, а не фича. В описании продукта для покупателей это обязательно проговаривается
явно. Офлайн-распознавания нет: без интернета диктовка не работает.

## Правила кода

- Комментарии в код не добавляй без прямой просьбы.
- C#: `TreatWarningsAsErrors`, `Nullable enable`. nullable-предупреждения — тоже ошибки.
- Тексты пользователю и в логи — по-русски.
- Имена методов и тестов — английские, без пробелов и спецсимволов: имя теста
  используется как описание проверки в `docs/ACCEPTANCE.md`.
- Тест на каждое новое поведение: `apps/agent/tests/`, `apps/web/test/`,
  `tools/speechpad-license-portal/tests/`.

## Проверено вручную

Сценарий покупателя отработан на настоящем запуске собранного релиза: запуск
`Speechpad.exe` → регистрация `.lic` → двойной щелчок → лицензия установлена →
`--license-info` показывает `valid`. Окно установки кликами не проверялось.
